# 3단계 · 사후학습 (식품 리뷰 적응)

KcELECTRA-base-v2022를 우리 리뷰로 한 번 더 학습해 식품 리뷰 표현에 익숙하게 만든 단계입니다. 결과는 5단계 감성 분류기의 출발점입니다.

- 학습 데이터: 같은 문장은 1번만 남긴 494,941건(`train.jsonl`), 검증·시험 각 2,000건. 정답 300리뷰와 그 묶음 리뷰는 학습에서 뺐습니다.
- 방식: ELECTRA 바꿔치기 판별(작은 생성기가 단어를 바꾸고, 본 모델이 어느 단어가 바뀌었는지 맞힘).
- 3에폭까지 학습했지만 감성 분류 점수가 1~3에폭이 같아서 **1에폭 결과만 남겼습니다**: `frozen-encoder/`. 학습용 `train.jsonl`과 생성기는 지웠고, 다시 학습하려면 `prepare_data.py`부터 돌리면 됩니다.
- 감성 분류 교차검증 정확도: 원래 모델 0.793 → 사후학습 0.845.

| 파일 | 내용 |
| --- | --- |
| `prepare_data.py` | 학습·검증·시험 데이터 만들기(`train.jsonl`은 필요할 때 다시 생성) |
| `train_stage1.py`, `stage1_core.py` | 학습(1000스텝마다 이어하기 저장, PC가 갑자기 꺼져도 이어서 진행) |
| `load_frozen.py` | 다른 단계에서 인코더 불러오기 |
| `results.json`, `history.json` | 학습 결과와 1에폭을 고른 이유 |
