# 5단계 · 감성 분류

리뷰를 의견 단위로 자르고, 단위마다 긍정 / 부정 / 평가 아님을 붙입니다.

| 폴더 | 내용 |
| --- | --- |
| `단위나누기/` | Kiwi로 문장을 나눈 뒤 `-는데`, `-지만`, `-고`, `-면서` 같은 연결어미에서 한 번 더 자름(`kiwi_units.py`). '맛있는 데'로 잘못 분석된 `-는데`도 자르고, '먹고 있어요'처럼 보조동사·조사가 붙으면 자르지 않음. 정답 의견의 84.2%를 단위 하나로 찾음 |
| `분류기/` | 3단계 사후학습 KcELECTRA를 정답 단위로 미세조정해 평가한 결과(`cv_unit_sentiment.py`, 리뷰 기준 5겹 × 3회) |

- 교차검증 정확도: 원래 모델 0.793 / 사후학습 v2 0.828 / **v3 1에폭 0.845** (macro F1 0.810).
- 가장 약한 것은 "평가 아님"(F1 약 0.66)이고, `learning-curve.json`상 정답을 늘리면 더 오릅니다.
- 실제 분석용 분류기는 6단계 `run_product.py`가 없으면 정답 전체로 새로 학습해 씁니다.
