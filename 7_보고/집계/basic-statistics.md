전체 평균은 **4.8771점**, 1~2점은 **3,207건, 0.4994%**다. 평균은 모든 리뷰를 동일하게 가중한 값이다. 상품 평균들을 동일 가중해 평균낸 값과 다르다.

상품별 리뷰 수는 매우 다르다. 상위 25개 상품이 전체 리뷰의 70.18%를 차지하며, 리뷰 100건 미만 상품은 280개다. 상품의 낮은 별점 건수와 비율을 구분해서 본다.

위 표는 리뷰 100건 이상 상품을 1~2점 비율로 정렬한 상위 5개다. 그래프 04는 같은 기준의 상위 20개를 표시한다. 오차막대는 Wilson 95% 구간으로, 건수가 적은 상품의 비율이 얼마나 불안정한지 함께 보여준다.

별도 우선 확인 후보는 `리뷰 100건 이상`이면서 `1~2점 비율의 Wilson 95% 하한 > 전체 1~2점 비율`인 83개다. 이는 탐색용 선별 기준이다. 다중 비교 보정이나 일반·한달사용 리뷰의 반복 관측을 반영한 검정이 아니므로 통계적으로 확정된 문제 상품이라는 뜻은 아니다. 기준 미달 상품도 전체 CSV에 포함했다.

절대 건수로는 칵테일새우 `4320235869`의 1~2점이 183건으로 가장 많지만 비율은 0.2200%로 전체보다 낮다. 리뷰가 많은 상품이라는 이유만으로 문제 상품으로 판단하면 안 된다. 명태포 `7826600725`는 7,374건 중 74건, 1.0035%다.

저별점의 기본 정의는 **1~2점**이다. **1~3점** 건수·비율도 같이 저장했다. 별점으로 텍스트의 긍정·부정이나 불만 원인을 확정하지 않았다.

## 월별·계절별 분포

1~12월이 있는 **2025년**을 연간 분포의 기준으로 사용했다. 2025년은 279,853건이다. 상품별 12개월 그리드를 만들었으며 리뷰가 없는 월의 건수는 0, 평균 별점·저별점 비율은 결측값이다. 2025년 리뷰가 전혀 없는 상품의 최다 월·연간 비중도 결측값이다.

최다 리뷰 월은 **실제 리뷰 건수**를 기준으로 선택했다. 동률인 월은 `peak_month_ties_2025`에 모두 보존했고, 단일 최다 월 필드는 가장 이른 월이다. 월 길이 차이를 볼 수 있도록 달력 일수로 나눈 일평균 리뷰 수도 저장했다. 계절별 최다 계절은 일평균을 기준으로 계산했다.

| 상품 ID | 상품명 요약 | 2025년 최다 리뷰 월 | 해당 월 리뷰 수 | 2025년 리뷰 중 비중 |
| --- | --- | ---: | ---: | ---: |
| 7826600725 | 명태포 700g+700g | 10월 | 540 | 29.70% |
| 141260081 | 명태포 슬라이스 700g | 1월 | 629 | 20.12% |
| 6999226700 | 국내산 새우 1kg | 10월 | 1,443 | 30.57% |
| 4868935576 | 노르웨이 생연어 | 8월 | 1,095 | 19.25% |

이는 2025년의 리뷰 집중 시점을 기술한 결과다. 반복되는 계절성이나 제철 판매량을 입증하는 결과가 아니다. 예를 들어 몬스터크랩 `12677567501`은 2025년에 리뷰가 등장하는 월이 11~12월뿐이며 12월 비중이 98.90%다. 상품 판매 시작·상품 ID 운영 변화·데이터 범위를 먼저 확인해야 하며 이를 겨울 계절성으로 단정할 수 없다.

2026년과의 반복 패턴 비교는 양쪽 연도 모두 달력상 완료된 **1~9월**만 사용했다. 비교 대상은 각 연도 해당 9개월에 리뷰가 100건 이상이고, 리뷰가 있는 월이 6개월 이상인 113개 상품이다. 그중 월별 일평균 리뷰 수의 Pearson 상관계수가 0.5 이상이고, 최다 리뷰 월이 동률 없이 같거나 1개월 차이인 18개를 반복 관찰 후보로 표시했다. 이는 사전에 지정한 탐색 규칙이며 확정적인 계절성 검정이 아니다. 그래프 09는 그중 2025년 리뷰가 300건 이상인 예시 6개다.

봄은 3~5월, 여름은 6~8월, 가을은 9~11월, 겨울은 1~2월과 12월이다. 계절별 표와 그래프 08의 겨울은 **2025년 달력 내 두 구간을 합친 것**이며 연속된 하나의 겨울이 아니다.

해석 시 다음 조건을 반영한다.

- 2025-05-31은 전체 데이터에 리뷰가 없다. 실제 무리뷰와 수집 누락 중 어느 쪽인지 미확정이며 보간하지 않았다. 달력 일수 분모에는 포함했고 월별 표의 `dates_without_any_review`에 표시했다.
- 2026년 10월은 13일 16:49:47까지다. 연월별 표·그래프에는 부분 기간으로 포함하고 연도별 패턴 비교에서는 제외했다. 이 달의 일평균은 마지막 부분 일자를 포함한 13일로 나눈 참고값이다.
- 상품별 판매 시작일·종료일과 품절 기간은 알 수 없다. 첫 리뷰 일자를 판매 시작일로 간주하지 않았다. CSV의 `first_review_date`, `last_review_date`는 리뷰 관측 기간일 뿐이다.
- 리뷰는 판매·주문·구매자 수가 아니다. 일반 410,697건과 한달사용 231,475건을 각각 리뷰 한 행으로 포함했으며, 리뷰 유형별 별점 분포도 따로 저장했다.
- 상품 노출·행사·리뷰 작성 지연과 매장 전체 규모 변화도 월별 패턴에 영향을 줄 수 있다. 원인을 이 통계만으로 확정하지 않는다.

## 산출물과 재실행

모든 CSV는 Excel에서 읽기 쉬운 UTF-8 BOM이다. 한글 요약표 2개는 아래 상세 분석표의 핵심 컬럼을 보기 좋게 바꾼 것이다.

| 파일 | 내용 |
| --- | --- |
| `overall_rating_distribution.csv` | 전체 별점 1~5점 건수·비중, 5행 |
| `product_rating_distribution.csv` | 전체 539상품의 별점별 건수·평균·저별점·관측 기간 |
| `low_rating_candidates.csv` | 탐색 기준을 만족하는 83상품 |
| `product_rating_by_review_type.csv` | 상품·일반/한달사용별 별점 분포, 1,047행 |
| `overall_year_month_statistics.csv` | 전체 22개월의 별점·리뷰 수·달력 범위 |
| `product_year_month_statistics.csv` | 539상품 × 22개월, 11,858행, 월별 1~5점 실제 건수 포함 |
| `product_monthly_2025.csv` | 539상품 × 12개월, 6,468행 |

| `product_seasonality_summary.csv` | 539상품의 최다 월·계절·연도별 패턴 비교 |

원본 별점 건수와 상품별·연월별·리뷰 유형별 합계가 모두 일치하는지 검증했다. 상품별 연간 월 비중은 리뷰가 존재하는 상품에서 100%로 합산된다. 입력 파일 SHA256도 동일함을 확인했다. PNG 9장은 실제 이미지를 확인했으며 긴 상품명이 겹치던 그래프의 행 간격을 수정했다.

재실행 코드: [analyze_basic_statistics.py](../../scripts/analyze_basic_statistics.py).

```powershell
python scripts/analyze_basic_statistics.py --reports 7_보고/집계/basic_statistics/new-run --figures 7_보고/집계/figures/basic-statistics-new-run
```

기존 결과를 의도적으로 갱신할 때만 `--overwrite`를 사용한다. 이 스크립트는 통계와 PNG만 생성하며 리뷰 데이터, AI 초안, 모델, 상품 매핑표를 변경하지 않는다.
